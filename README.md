# C++ Practice & Coursework Projects 🚀

This repository contains a collection of C++ console applications, coursework exercises, and practice projects I developed while learning programming fundamentals.

## 📂 Projects Included

### 1. Student Grading System (`/student-grading-system`)
- **Description:** A console application that collects student grades, validates input, calculates class averages, finds min/max scores, converts scores to letter grades, and sorts them.
- **Key Concepts:** Arrays, loops (`for`, `while`), conditional statements, and STL `<algorithm>`.

### 2. Personal ID Card (`/personal-id-card`)
- **Description:** A console-based personal introduction and identification card application showcasing basic text formatting and output handling.
- **Key Concepts:** Basic I/O operations (`cout`), string manipulations, and formatting.

### 3. C++ Practice Sandbox (`/cpp-practice-sandbox`)
- **Description:** A collection of general practice trials, syntax experiments, and fundamental C++ exercises.
- **Key Concepts:** Core language syntax, variables, and experimental logic.
